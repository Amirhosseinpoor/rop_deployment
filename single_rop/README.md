# Single ROP: Ophthalmic CV Diagnostic Pipeline

The `single_rop` module is a high-fidelity Computer Vision application dedicated to the automated detection and classification of **Retinopathy of Prematurity (ROP)** from retinal fundus images.

---

### 1. Models (`models.py`)
The module persists diagnostic results in the **`PredictionLog`** table, which serves as the primary clinical record for ROP screenings.

- **`user` (FK)**: Links the record to the clinician (User) who performed the scan.
- **Diagnostic Metrics**:
    - `predicted_class`/`probability`: Primary "Plus disease" (Plus/No Plus) results.
    - `stage_class`/`stage_probability`: Disease progression (Normal, Stage 0–5).
    - `zone_class`/`zone_probability`: Anatomical location (Zone 1, 2, or 3).
    - `final_decision`: Aggregate clinical recommendation based on ICROP/ETROP guidelines.
- **Storage & URLs**:
    - `image`: Original retinal fundus upload.
    - `segmented_image`: Vascular overlay generated by the segmentation model.
    - `image_url`/`segmented_image_url`: Optimized URL fields for frontend rendering.
- **Human-in-the-loop**:
    - `corrected_class`, `stage_corrected_class`, `zone_corrected_class`: Fields for clinician overrides to support continuous model evaluation.
    - `classification_status`: Tracking flag (1 = Auto, -1 = Misclassified).

---

### 2. Core Logic & AI Pipeline (`utils.py`)
The pipeline executes a synchronous multi-model inference chain.

#### **Step-by-Step Data Flow:**
1.  **Segmentation (`UnetPlusPlus`)**:
    - **Model**: ResNet18 encoder with Unet++ decoder.
    - **Input**: `(512, 512, 3)` Image tensor.
    - **Logic**: Isolates the retinal vasculature.
    - **Output**: Binary mask `(512, 512)` indicating vessel density.
2.  **Plus Disease Classification (`EfficientNet-B4`)**:
    - **Input**: Segmented vascular mask (converted back to 3-channel).
    - **Logic**: Classifies tortuosity and dilation.
    - **Output**: `{"Plus", "No Plus"}` with confidence scores.
3.  **Staging (`EfficientNet-B6`)**:
    - **Input**: Original image `(224, 224)`.
    - **Logic**: Detects extraretinal fibrovascular proliferation.
    - **Output**: Softmax probability over 7 classes (Normal, Stages 0–5).
4.  **Zoning (`EfficientNet-B4`)**:
    - **Logic**: Predicts Zone 1/2 from logits; falls back to Zone 3 if confidence < 0.5.
5.  **Expert Decision System (`compute_final_decision`)**:
    - Logic aggregates the triple (Zone, Stage, Plus) into a recommendation (e.g., "Treatment", "Follow-up <= 1 week") based on clinical flowcharts.

#### **I/O Example:**
- **Input**: Retinal fundus image (JPEG).
- **Output Dictionary**:
  ```json
  {
    "predictions": {"class_name": "Plus", "class_prob": "0.985"},
    "stage_prediction": {"stage_name": "Stage 3", "stage_prob": "0.942"},
    "final_decision": "Treatment",
    "inference_time": "1450 ms"
  }
  ```

### 3. Views & Handlers (`views.py`)
- **`home(request)`**:
    - **Multi-image Support**: Handles batch uploads via `request.FILES.getlist('files')`.
    - **Aggregation**: Calls `get_results_for_images` to find the "worst-case" eye (highest severity) for the primary display.
    - **Persistence**: Automates `PredictionLog` creation if the user is authenticated.
- **`predict(request)`**:
    - A stateless JSON API endpoint (`@csrf_exempt`) for third-party service integration.
    - Validates file presence and returns the `aggregated` results and `per_image` breakdown.
